**Description of Project**

The purpose of this project is to create an AI that challenges the player to a game of Tic-Tac-Toe. The Minimax search method is implemented so that the AI makes the best move depending on the state of the game. This project examines how search algorithms decide to make the best choice based on several possible situations.
